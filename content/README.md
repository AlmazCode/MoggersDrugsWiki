# Содержимое вики

`articles.json` — 16 русских статей для игроков. Формат: массив статей с `id`, `title`, `description` и `sections`. Раздел содержит `heading`, обычный текст `paragraphs`, списки `bullets` или таблицу `table` с `headers` и `rows`. HTML в тексте не используется.

Статьи сверены с текущими игровыми сервисами, обработчиками меню и командами в `src/main/java/dev/moggers/drugs`. Они описывают реализованные действия: например, склад обслуживает подготовленные добавки циклов, а расходники анализа и тара берутся из инвентаря игрока.

`../src/data/catalog.json` экспортируется командой:

```sh
npm run catalog -- /путь/к/MoggersDrugs
```

Скрипт запускается из любой директории, использует Java 25, ранее собранный JAR плагина и SnakeYAML из локального Maven-кэша. Он компилирует актуальные `BlueprintCatalog`, `Blueprint`, `StationType`, `StationTier` и `PlantCatalog` в отдельный временный каталог. Вычисленные Java-каталогами данные сериализуются в JSON; рабочие результаты Maven и Paper не изменяются.

Проверяется наличие 16 элементов, 58 источников, 62 профилей и 15 вариантов станций, уникальность координат, а также 27 / 33 / 57 обязательных клеток для трёх уровней. Дополнительно включён складской узел на основе проверок `WarehouseNetwork.register`.

Координаты станций отсчитываются от центра основания. Перед — `+z`, панель — `(0,1,1)`. Вход извлекателя — `(0,1,-1)`, выходной выбрасыватель — `(-1,1,1)`. Порт склада — `(0,1,-1)` у базового / обычного уровня и `(0,1,-3)` у научного. `FORWARD` означает сторону передней бочки, а не фиксированный мировой юг: всю схему разрешено повернуть.

`AIR` в требованиях станции — обязательная пустая клетка. Отсутствующая клетка складского узла — не проверяемое пространство: его свободные углы и верхние клетки не требуют обязательного воздуха. Направления медных блоков у узла не проверяются.

Массы базы и бонусов растений выражены в микрограммах; 1 000 000 мкг = 1 г. `maturityMinutes` описывает время достижения целевого бонуса в подходящем биоме. Уровневые значения в `limits` относятся к стандартным правилам этой сборки, а не к произвольным изменениям серверного баланса.
