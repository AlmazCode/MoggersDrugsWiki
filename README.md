# MoggersDrugs — вики для игроков

[Открыть вики на GitHub Pages](https://almazcode.github.io/MoggersDrugsWiki/)

Полноценный статический сайт на React / Vite, без базы данных и внешних сервисов. Интерфейс и руководства на русском. Автор: **MoggersDev**.

- 15 вариантов станций и складской узел: интерактивные 3D-чертежи, реальные модели и текстуры Minecraft 1.21.11, вращение и масштаб, выбор и разнесение слоёв, сведения о блоке, направления, подсчёт и копирование материалов.
- Плоские схемы всех слоёв доступны независимо от WebGL. Обязательный воздух отличается от ячеек, которые плагин не проверяет.
- Справочник 16 элементов, 58 растений и 62 региональных профилей: свойства, состав, биомы, время созревания, поиск и фильтры.
- 16 подробных руководств: производство, качество, износ, эффекты и сочетания, личные формулы, исследования, склад, права, команды и решение проблем.
- Мобильная навигация, поиск с клавиатуры, ссылки на отдельные статьи/элементы/растения/чертежи.

## Запуск

Нужен Node.js 20.19+ или 22.12+ (проверено на 24.21.0).

```sh
cd MoggersDrugsWiki
npm ci
npm run dev
```

Сайт: http://127.0.0.1:5173. Готовый production-предпросмотр:

```sh
npm run build
npm run preview
```

Предпросмотр: http://127.0.0.1:4173. Проверка данных и моделей: `npm test`.

## Размещение

Для GitHub Pages выполните `npm run build:pages` и включите обновлённую папку `docs/` в коммит. В настройках репозитория выберите **Settings → Pages → Deploy from a branch → main → /docs**.

Для другого хостинга скопируйте **содержимое** `dist` после `npm run build` в каталог любого статического HTTP-хостинга. Дополнительный сервер API, Minecraft-сервер и настройка SPA fallback не нужны: маршруты используют `#`. Работает как в корне домена, так и в подкаталоге `/wiki/`. Шрифты, текстуры и данные включены в сборку; внешние запросы при просмотре не требуются.

Проверяйте через HTTP, а не двойным кликом по HTML: браузеры ограничивают загрузку модулей с `file://`. Сайт можно разместить отдельно от сервера Minecraft. Он не раскрывает сохранённые игроками формулы — только общие правила плагина.

## Обновление содержания

`src/data/catalog.json` экспортируется из реальных Java-каталогов. В корне вики выполните `npm run catalog -- /путь/к/MoggersDrugs`. Сначала соберите плагин командой `mvn package` на Java 25. Экспортёр использует JAR из `target` и SnakeYAML из локального кэша Maven. Подробности в `scripts/export-catalog.py`. Статьи лежат в `content/articles.json`; после изменения механик их нужно сверить с кодом и обновить вручную.

Minecraft-ресурсы копируются из официального проверенного клиента без изменения PNG. Источник и SHA-1 в `scripts/minecraft-source.json`, SHA-256 каждой текстуры — в `src/data/minecraft-assets.json`.

```sh
python3 scripts/extract-minecraft-assets.py /путь/к/minecraft-1.21.11-client.jar
```

Полный клиент в сайт не включён. Геометрия горшка и статичной книги перенесена из vanilla block-entity renderer; об этом указано в manifest. Лицензии и источник доступны на странице `credits.html`.

Вики отражает стандартные правила текущей версии. Изменения настроек конкретного сервера могут менять параметры.
